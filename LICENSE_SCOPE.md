# Licence scope and upstream provenance

The [MIT licence](LICENSE) applies to original additions and modifications made
in this fork by its contributors. It does **not** grant rights in inherited
upstream code or relicense that code.

The inherited baseline is
[`bremor/public_transport_victoria` commit `dc4bf2b4a50e7b335a9d736a00e42fa8b52c21bb`](https://github.com/bremor/public_transport_victoria/commit/dc4bf2b4a50e7b335a9d736a00e42fa8b52c21bb),
version 0.7. That upstream repository contains no declared software licence at
the time this release candidate was prepared. Its authors retain their rights;
this fork cannot supply their permission by adding its own licence.

Original additions include the route disruption parser, alert coordinator and
alert sensor, regression tests and synthetic fixtures, development/release
scripts, and this fork's documentation. In modified inherited files, MIT covers
only the original changes made here, not the pre-existing contents. Git history
and a diff against the recorded baseline identify that boundary. Preserve
upstream authorship and any separately attributed third-party material.

HACS/GitHub may identify the root licence as MIT. That metadata does not expand
its scope to all inherited source. The archive includes both this scope statement
and the MIT text so users of the packaged integration see the same distinction.

The integration's existing Creative Commons Attribution 4.0 notice concerns PTV
data. It is separate from the software licences and remains unchanged.
